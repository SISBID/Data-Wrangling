
## Module 1: Data Wrangling with R 🤠

This repository contains all material and hosts the website for the Summer Institute for Statistics in Big Data ([SISBID](https://si.biostat.washington.edu/institutes/sisbid)) at University of Washington. The course is currently taught by [Carrie Wright](https://github.com/carriewright11) and [Ava Hoffman](https://github.com/avahoffman).

This course covers major topics in data wrangling. We focus on the Tidyverse "dialect" of R. We also touch on reproducibility practices with R and Git/GitHub.

Check out the deployed website here for easy browsing: http://sisbid.github.io/Data-Wrangling/
